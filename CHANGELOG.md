# 1.0.0-pl

- Первый выпуск для чистой установки в MODX 3.
- Нативные вкладки с таблицами дат и типов событий, поиск, сортировка, фильтр года и модальные окна редактирования.
- Один начальный тип события: «Экзамен» (exam). Собственные типы можно создавать в админке.
- Сниппет ScheduleDates с фильтрами, группировкой по месяцам и переопределяемыми чанками, включая вывод в select.
- Отдельный вывод каждого события и классы для прошедших и предстоящих дат.
