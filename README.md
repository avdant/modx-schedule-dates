# ScheduleDates для MODX 3

Дополнение для расписания экзаменов, проверок и других событий. Даты добавляются в админке, а на сайте выводятся через сниппет `ScheduleDates`.

## Возможности

- Добавление событий: дата, название, тип, описание и публикация.
- Несколько разных событий в один день.
- Добавление одинаковых событий сразу на несколько дат и копирование события на новые даты.
- Создание и редактирование типов событий.
- Поиск, сортировка и фильтр по году в админке.
- Вывод расписания по месяцам, списком или в поле выбора даты.
- Отдельные расписания для разных типов событий.
- Вывод только предстоящих событий.
- Настройка оформления через чанки и CSS, включая выделение прошедших дат.

## Требования

- MODX Revolution 3.x.
- PHP 7.4 или новее с расширением mbstring.
- MySQL 5.7+ или MariaDB 10.2+.

## Установка

1. В админке MODX откройте «Приложения → Установщик пакетов».
2. Загрузите архив `scheduledates-1.1.0-pl.transport.zip` и установите пакет.
3. Обновите страницу админки и откройте «Приложения → ScheduleDates».

Для доступа к дополнению нужно право `settings`.

## Работа с расписанием

На вкладке **«Даты событий»** выберите год и нажмите **«Добавить событие»**. Укажите дату, тип и название, при необходимости заполните описание. Чтобы событие появилось на сайте, отметьте публикацию.

Для изменения события дважды нажмите на строку таблицы или выберите «Редактировать» в контекстном меню. Там же можно удалить событие.

Чтобы добавить одинаковое событие на несколько дат, заполните общие поля один раз и нажимайте **«Добавить дату»** для каждой следующей даты. Лишние строки можно удалить. За одно сохранение можно указать до 366 дат; повторяющиеся даты учитываются один раз. Каждая дата сохраняется отдельным событием.

Чтобы использовать уже заполненное событие, выберите его в таблице и нажмите **«Добавить на другие даты»** на панели или в контекстном меню. Название, тип, описание и публикация будут заполнены. Выберите новые даты и сохраните. Исходное событие останется без изменений. Если событие с такой датой, названием и типом уже есть, его описание и публикация обновятся без создания дубля.

На вкладке **«Типы событий»** можно добавлять, переименовывать и удалять типы. В качестве примера уже создан тип **«Экзамен»** с кодом `exam`.

Каждому типу нужен уникальный код, например `exam` или `attestation`. Используйте от 1 до 20 символов: строчные латинские буквы, цифры, дефис и подчёркивание. Первый символ — буква.

Код используется для фильтрации расписания на сайте. Если изменить его в админке, события получат новый код автоматически, а параметр `type` в вызовах сниппета нужно будет изменить вручную. Удалить тип можно, только если у него нет событий.

## Вывод на сайте

Добавьте вызов сниппета в содержимое страницы, чанк или шаблон.

Все опубликованные события текущего года:

```modx
[[!ScheduleDates]]
```

Экзамены за выбранный год:

```modx
[[!ScheduleDates? &year=`2027` &type=`exam`]]
```

Только сегодняшние и будущие экзамены текущего года:

```modx
[[!ScheduleDates? &type=`exam` &upcoming=`1`]]
```

Для нескольких расписаний на одной странице добавьте отдельные вызовы с нужными кодами типов.

Используйте вызов с `!`, как в примерах: так расписание будет учитывать изменения дат и публикации без очистки кеша страницы. Неопубликованные события на сайте не отображаются.

### Параметры сниппета

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `year` | текущий год | Год расписания, от 1900 до 2100 |
| `type` | все типы | Код типа события, например `exam` |
| `upcoming` | `0` | `1` — показывать только сегодняшние и будущие даты в выбранном году |
| `css` | `1` | `1` — подключать стили дополнения; `0` — использовать только стили сайта |
| `emptyText` | Даты пока не назначены. | Сообщение, если событий нет |
| `tpl` | `scheduledatesRow` | Чанк одного события |
| `tplMonth` | `scheduledatesMonth` | Чанк месяца |
| `tplWrapper` | `scheduledatesWrapper` | Чанк обёртки всего расписания |
| `groupByMonth` | `1` | `0` — выводить события без группировки по месяцам; `tplMonth` не используется |
| `showEmptyMonths` | `0` | `1` — показывать все 12 месяцев, включая пустые; работает при `groupByMonth=1` |

## Настройка оформления

Чанки находятся в категории **ScheduleDates**. Можно изменить их или создать свои и указать в параметрах `tpl`, `tplMonth` и `tplWrapper`.

Сниппет обрабатывает каждое событие через `tpl`, объединяет события месяца через `tplMonth` и передаёт результат в `tplWrapper`. Если в один день несколько событий, каждое выводится отдельно.

### Плейсхолдеры события — `tpl`

| Плейсхолдер | Значение |
| --- | --- |
| `[[+id]]` | ID события |
| `[[+date]]` | Дата в формате `2027-02-01` |
| `[[+dateFormatted]]` | Дата в формате `01.02.2027` |
| `[[+day]]` | День месяца, например `01` |
| `[[+month]]` | Номер месяца, например `02` |
| `[[+year]]` | Год |
| `[[+monthName]]` | Название месяца |
| `[[+weekday]]` | День недели |
| `[[+title]]` | Название события |
| `[[+type]]` | Код типа события |
| `[[+typeName]]` | Название типа события |
| `[[+description]]` | Текст описания |
| `[[+descriptionHtml]]` | Описание с переносами строк; пустая строка, если описания нет |
| `[[+isPast]]` | `1`, если дата прошла, иначе `0` |
| `[[+dateClass]]` | `is-past` для прошедшей даты, `is-upcoming` для сегодняшней или будущей |

Названия и описания выводятся как текст: HTML и MODX-теги в них экранируются.

### Плейсхолдеры месяца — `tplMonth`

| Плейсхолдер | Значение |
| --- | --- |
| `[[+output]]` | Готовая разметка событий месяца |
| `[[+month]]` | Номер месяца |
| `[[+monthName]]` | Название месяца |
| `[[+year]]` | Год |
| `[[+count]]` | Количество событий месяца |

У пустого месяца `output` пустой, а `count` равен `0`. Чтобы вместо пустого списка вывести тире, используйте:

```modx
[[+output:default=`—`]]
```

### Плейсхолдеры обёртки — `tplWrapper`

В обёртке доступны `[[+output]]` — готовая разметка расписания, `[[+year]]` — год, `[[+type]]` — выбранный код типа и `[[+count]]` — общее количество событий.

Если событий нет, стандартная обёртка выводит сообщение `emptyText`. Собственная обёртка получает пустой `output`, `count=0` и текст в `[[+emptyText]]`.

## Даты в поле выбора

В комплекте есть чанки для вывода событий в `<select>`:

```modx
[[!ScheduleDates?
    &type=`exam`
    &tpl=`scheduledatesOption`
    &tplWrapper=`scheduledatesSelect`
    &groupByMonth=`0`
    &css=`0`
]]
```

В `scheduledatesSelect` имя поля — `exam_date`. Значение каждого пункта — дата в формате `YYYY-MM-DD`.

Для своего поля создайте, например, чанк `scheduleSelect`:

```html
<select name="event_id" required>
    <option value="">Выберите событие</option>
    [[+output]]
</select>
```

И чанк `scheduleOption`:

```html
<option value="[[+id]]">[[+dateFormatted]] — [[+title]]</option>
```

Укажите `scheduleSelect` в параметре `tplWrapper`, а `scheduleOption` — в `tpl`. Остальные параметры оставьте как в примере выше. Здесь значением пункта служит ID, чтобы различать события, назначенные на одну дату.

## Выделение прошедших дат

Добавьте `[[+dateClass]]` в класс элемента своего чанка события:

```html
<span class="schedule-day [[+dateClass]]">[[+day]]</span>
```

И задайте цвета в CSS сайта:

```css
.schedule-day { color: #176b91; }
.schedule-day.is-past { color: #999; }
```

Сниппет сам определяет прошедшие даты по часовому поясу PHP/MODX. Сегодняшняя дата считается предстоящей.

## Удаление

При удалении пакета события и типы сохраняются в таблицах `{table_prefix}scheduledates_events` и `{table_prefix}scheduledates_types`. Для полного удаления данных эти таблицы нужно удалить отдельно. Перед удалением сделайте резервную копию.
